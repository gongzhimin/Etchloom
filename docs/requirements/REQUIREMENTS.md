# 系统级需求与验收标准规范 (REQUIREMENTS)

> **文档标识**：REQ-SYS-SPEC  
> **上级依据**：项目立项使命与古典版画数字艺术工程愿景  
> **最新状态**：正式发布 (v0.1.7)  

---

## 1. 系统业务目标

Etchloom（莫兰迪古典铜版画工作室）是一款**离线优先 (Local-First)、跨平台桌面端数字化古典版画工坊**。其核心目标是：
1. **突破传统滤镜玩具**：将日常真实照片转化为具有乔治·莫兰迪、丢勒等古典大师质感的纯正矢量线条母版；
2. **还原版画物理真知**：构建微米级二维连续场虚拟铜版与偏微分方程 (2D PDE) 仿酸液咬蚀物理引擎；
3. **赋予数字反悔超能力**：在保留古典手工刻线、防酸漆修版、试印压痕等真实质感的同时，赋予创作者即时重置腐蚀、快照回滚与高保真导出能力。

---

## 2. 核心端到端业务场景

### [SCEN-001] 阶段 1 · 制作线条母版 (Master Generation)
* **用户目标**：用户载入真实照片，调整空间结构与排线密集度，生成严谨的矢量母版图稿。
* **业务流程**：
  1. 支持拖拽或选择本地图片（JPG/PNG/WebP），系统自动执行分辨率限制与长宽比适配；
  2. 启动 5 阶段管线：灰度色调重构 $\rightarrow$ 空间骨干轮廓提取 $\rightarrow$ 微分曲面顺形排线合成 $\rightarrow$ 留白与暗部调子平衡 $\rightarrow$ 双层古典外框集成；
  3. 支持在 Lightbox 中 1:1 像素级或自适应缩放检查各图层，并可一键独立导出矢量 SVG 或位图。

### [SCEN-002] 阶段 2 · 蚀刻铜版与试印 (Virtual Plate Studio)
* **用户目标**：将阶段 1 生成的母版上版，进行亲手划破防蚀漆、酸槽腐蚀与填墨试印。
* **业务流程**：
  1. **工序 1 · 母版上版**：选择上版工艺（标准蚀刻划破保护漆 vs 干刻直刻起毛刺）、版面精度（900 / 1500 / 3000）与针尖力度；若已有修改版面，自动提供防覆写安全拦截与备份；
  2. **工序 2 · 亲手刻绘**：手持刻针修线、涂覆防蚀漆修抹遮蔽、刮磨器抛光，支持压感手写笔；
  3. **工序 3 · 控制腐蚀**：放入酸槽启动物理咬蚀；仪表盘实时显示累计秒数、刻槽深度微米数与腐蚀程度分档；支持随时暂停或**一键重新腐蚀（放弃过蚀、保留刻线并归零时间）**；
  4. **工序 4 · 填墨试印**：选择棉纸材质（粗纹棉纸、象牙白细纹纸、亚麻混纺纸、Rosaspina），调整墨量饱满度、压印压力与留墨调子，实时呈现正向印痕。

## 3. 全局非功能质量要求 (Quality Attributes)

* **[REQ-SYS-QUAL-001] 100% 离线与隐私安全**：所有算法模型（包括神经网络与物理算子）完全在用户本地运行，零外部网络 API 依赖，零隐私数据上传。
* **[REQ-SYS-QUAL-002] 硬件加速与降级韧性**：默认优先使用 WebGPU 加速推理与图像处理；若客户端环境不支持，无缝平滑降级至多线程 WebAssembly SIMD，保证极致性能与广泛兼容。
* **[REQ-SYS-QUAL-003] 桌面级打包紧凑度**：基于 Tauri v2 构建原生桌面端；Windows 安装包体积控制在 40MB 以内（采用 NSIS LZMA 固实压缩），macOS 支持 Apple Silicon 原生架构。

---

## 4. 系统级验收标准 (Acceptance Criteria)

* **[AC-SYS-001]** 自动化测试套件（`npm test`）全量执行通过率必须为 100%（当前 154+ 项用例全部通过）。
* **[AC-SYS-002]** 在酸槽腐蚀工序中，无论处于腐蚀中还是已暂停，点击【重新腐蚀】必须在 50ms 内清空深度、复原入酸前线径、重置计时并更新状态。
* **[AC-SYS-003]** 跨平台安装包（Windows Setup EXE / MSI、macOS DMG、Android APK）均能独立无网络启动并完整运行制版全流程。
