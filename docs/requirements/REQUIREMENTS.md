# 系统需求与验收标准

## 1. 系统目标

Etchloom 是一款面向版画艺术家、插画创作者与古典艺术爱好者的离线优先（Local-First）桌面与移动端数字化古典铜版画工坊应用。系统将日常真实照片转化为严谨的古典矢量排线母版，并在微米级连续物理场中高保真仿真铜版刻线、防酸漆保护、偏微分方程酸槽潜蚀与棉纸凹版压印过程。系统不提供云端协同或云端 SaaS 渲染，所有计算严格在用户设备本地闭环完成。

## 2. 业务场景

### [SCEN-001] 自然照片转化为古典铜版画母版
- **场景 ID**：SCEN-001
- **角色**：版画创作者
- **触发**：用户载入本地静态照片（JPG/PNG/WebP）或选择示范静物
- **期望结果**：系统经过 5 阶段离散计算管线，自动抽取感知结构线描、解算各向异性色调切线流场、提取空气透视主轮廓并生成顺形几何排线，在工作区呈现高保真母版，支持分图层无损缩放检查与 SVG 导出。

### [SCEN-002] 虚拟铜版刻绘、酸蚀与填墨试印
- **场景 ID**：SCEN-002
- **角色**：铜版画印制师
- **触发**：用户确认将母版上版至虚拟铜版工作室
- **期望结果**：系统分配连续物理场网格；用户可使用蚀刻划针、干刻针、防蚀漆、刮磨器进行交互修饰；放入酸槽后实时解算 2D PDE 侧蚀与纵向咬槽；支持随时暂停或一键重新腐蚀；最后填墨并在不同质感手工棉纸上完成凹版压印试印。

### [SCEN-003] 过咬蚀安全恢复与铜版资产保护
- **场景 ID**：SCEN-003
- **角色**：初学创作者
- **触发**：在酸槽中因时间过长发生过咬蚀，或误触重新上版
- **期望结果**：点击【重新腐蚀】立即安全归零刻深与计时，完整保留上版稿与手工刻线；在已有刻痕或清漆保护时重新上版，系统强制拦截并提供自动备份选项，杜绝用户创作资产被静默抹除。

## 3. 全局质量要求

- **[QUAL-001] 100% 离线隐私保证**：核心模型与物理算法完全运行于本地客户端，网络断开状态下功能无任何降级，零外部遥测与数据回传。
- **[QUAL-002] 确定性与零 NaN 容忍**：给定相同输入与 PRNG 种子，管线输出达到比特级一致；计算中严禁产生 `NaN` 或 `Infinity` 数值外溢。
- **[QUAL-003] 交互实时性与防抖调度**：参数拖拽响应延迟 $\le 60\,\text{ms}$，高频并发操作平滑抢占中断，界面无掉帧与死锁。
- **[QUAL-004] 紧凑跨平台打包**：基于 Tauri v2 打包，Windows 安装包体积 $\le 45\,\text{MB}$（NSIS LZMA 压缩），macOS 与 Android 均支持原生架构。

## 4. 系统验收标准

- **[AC-SYS-001]** 自动化测试套件（`npm test`）执行通过率必须为 100%（Pass Rate = 100%），零 Failure、零 Cancelled。关联场景：SCEN-001, SCEN-002。
- **[AC-SYS-002]** 在酸槽腐蚀中无论处于进行态还是暂停态，点击【重新腐蚀】在 $50\,\text{ms}$ 内清空槽深、复原线宽并重置计时器为 $0.0\,\text{s}$。关联场景：SCEN-002, SCEN-003。
- **[AC-SYS-003]** 针对已编辑铜版再次上版时，系统强制触发安全模态弹窗拦截，未确认前禁止覆写底层数组。关联场景：SCEN-003。
- **[AC-SYS-004]** 系统界面完整支持 `zh-CN`、`en-US`、`vi-VN` 三语动态切换，状态与操作文字保持 1:1 对齐，零 Emoji 字符残留。关联场景：SCEN-001, SCEN-002。

## 5. 分模块需求

### 5.1 领域核心模块 (core)
#### 5.1.1 承接的系统需求
引用场景：`SCEN-001`、`SCEN-002`、`SCEN-003`；引用验收标准：`AC-SYS-001`、`AC-SYS-002`。
#### 5.1.2 模块能力需求
- **[REQ-CORE-001] 五阶段母版离散计算管线**：提供线描感知、色调张量场、轮廓透视、曲率排线与母版合成的纯函数运算能力。边界：不负责文件 I/O 与 DOM 事件监听。来源：细化自 SCEN-001。
- **[REQ-CORE-002] 微米级虚拟铜版物理引擎**：维护 `depth`、`exposed`、`blocked`、`burr` 连续场，支持 4 种工具离散更新与 2D PDE 酸液侧蚀模拟。边界：不直接操作 HTMLCanvasElement。来源：细化自 SCEN-002。
- **[REQ-CORE-003] 预入酸基准快照与状态重置**：支持在入酸前锁存 `preEtchSnapshot` 并在重新腐蚀时原子化回滚槽深。边界：不负责 UI 按钮的禁用置灰。来源：细化自 SCEN-003。
#### 5.1.3 模块验收标准
- **[AC-CORE-001]** 连续物理场更新满足质量与能量守恒，被 `blocked` 覆盖的区域酸蚀刻深增量恒等于 0。关联：REQ-CORE-002。
- **[AC-CORE-002]** 矢量排线宽度计算完全免疫 `{x, y}` 结构体与极端浮点输入，输出严禁包含 `NaN`。关联：REQ-CORE-001。

### 5.2 调度与编排模块 (orchestration)
#### 5.2.1 承接的系统需求
引用场景：`SCEN-001`；引用验收标准：`AC-SYS-001`。
#### 5.2.2 模块能力需求
- **[REQ-ORCH-001] DAG 增量拓扑哈希缓存**：基于 DJB2 变体对各阶段参数计算敏感哈希，仅当下游参数变更时重算下游阶段。边界：不参与算法内部矩阵解算。来源：细化自 SCEN-001。
- **[REQ-ORCH-002] 高频调度抢占与防抖机制**：接收滑块输入时提供 $60\,\text{ms}$ 防抖，并在新任务到达时向旧任务派发 `AbortSignal`。边界：不持有 UI 组件实例。来源：模块特有（保证交互流畅度）。
- **[REQ-ORCH-003] 统一多格式工业级导出**：将矢量集合与位图数据序列化为标准 SVG、带 DPI 元数据的 PNG 及 Base64 编码的铜版 JSON 备份。边界：不执行底层浏览器原生下载弹窗。来源：细化自 SCEN-001。
#### 5.2.3 模块验收标准
- **[AC-ORCH-001]** 仅修改阶段 4 参数时，阶段 1–3 必须命中缓存，重算耗时 $\le 20\,\text{ms}$。关联：REQ-ORCH-001。
- **[AC-ORCH-002]** 连续提交 50 次调度时，旧任务必须立即接收到 `aborted` 标记，仅最后一次任务落盘。关联：REQ-ORCH-002。

### 5.3 服务网关模块 (services)
#### 5.3.1 承接的系统需求
引用场景：`SCEN-001`；引用验收标准：`AC-SYS-001`。
#### 5.3.2 模块能力需求
- **[REQ-SERV-001] 本地模型网关与自动发现**：优先探测本地 `127.0.0.1:7861` Python CUDA 推理服务并执行 HTTP 通信。边界：不负责启动或终止 Python 进程。来源：细化自 SCEN-001。
- **[REQ-SERV-002] 纯几何模式无断点优雅降级**：当服务不可达或超时（4000ms）时，无缝切换为前端 DoG 几何边缘滤波，杜绝白屏。边界：不向调用方泄漏具体网络错误。来源：模块特有（保障 100% 离线可用性）。
#### 5.3.3 模块验收标准
- **[AC-SERV-001]** 在网络断开且后端未启动时调用推断接口，网关在 $50\,\text{ms}$ 内完成离线退避判定并返回合法的灰度线描数据。关联：REQ-SERV-002。

### 5.4 工坊界面模块 (ui)
#### 5.4.1 承接的系统需求
引用场景：`SCEN-001`、`SCEN-002`、`SCEN-003`；引用验收标准：`AC-SYS-001`、`AC-SYS-002`、`AC-SYS-003`、`AC-SYS-004`。
#### 5.4.2 模块能力需求
- **[REQ-UI-001] 两阶段古典工坊进阶模式**：提供【阶段 1 · 制作母版】与【阶段 2 · 蚀刻铜版】双工作区切换与状态保持。边界：不包含外部多窗口管理。来源：细化自 SCEN-001, SCEN-002。
- **[REQ-UI-002] 四态离散酸液机与仪表盘控制**：实现 Standby / Biting / Paused / Standby 状态机与物理秒数、刻深读数联动。边界：不直接解算 PDE 方程。来源：细化自 SCEN-002。
- **[REQ-UI-003] 上版守卫拦截模态与历史撤销栈**：检测到铜版修改时弹出安全确认对话框；提供撤销栈对称恢复能力。边界：不修改后端导出格式。来源：细化自 SCEN-003。
- **[REQ-UI-004] 三语国际化与响应式画布渲染**：支持中文、英文、越南语无 Emoji 切换与高 DPI 视网膜画布适配。边界：不负责外部字体网络拉取。来源：细化自 SCEN-001。
#### 5.4.3 模块验收标准
- **[AC-UI-001]** 切换语言时所有界面 CTA 与提示文字即时变更，零硬编码中文残留。关联：REQ-UI-004。
- **[AC-UI-002]** 在已有刻痕或防腐漆时触发上版，必须弹出拦截弹窗，提供“覆盖并备份”与“取消”选项。关联：REQ-UI-003。
