# 只用素描底图生成版画：可行性调研

更新：2026-09-14。

## 结论

这条路线可行，而且很适合成为 Etchloom 的独立创作模式。但“素描底图”必须区分为两类：

1. **纯线稿**只记录轮廓、转折和少量材质线，没有足够信息还原原场景的阴阳明暗。
2. **调子素描**同时记录轮廓和低频灰调、排线密度或阴影标记，可以独立驱动版画。

当前工作台显示的结构素描接近第一类。它故意删除大面积灰调以便诊断轮廓，因此若完全丢弃净化灰度图，最终版画只能保留形，无法忠实保留原照片的明暗。算法可以生成新的合理明暗，但那属于再创作，而不是转换。

## 为什么纯线稿不能唯一决定明暗

同一条圆形轮廓可以表示球体、圆盘、洞口或平面图形；同一张脸部线稿在左上光、右上光和逆光下会产生完全不同的排线。纯线稿没有光源、材质、深度和表面法线，因而“从线稿恢复原始阴影”没有唯一答案。

SHAD3S 说明了另一条可行路径：以线稿和用户指定光照为条件，合成符合三维感觉的排线与阴影。它证明纯线稿可以生成有说服力的结果，也说明额外的光照条件不可缺少；输出是模型推断的合理方案，而不是原场景明暗的恢复。

- SHAD3S 项目：<https://bvraghav.com/shad3s/>
- SHAD3S 论文：<https://arxiv.org/abs/2011.06822>

## 三种可实施模式

### A. 轮廓版：纯线稿直接制版

输入线条直接转为受保护的主轮廓、结构线和材质线。区域内部保持留白，只加入很轻的装饰排线。

优点：忠实、干净、完全可解释，适合建筑线稿、植物图谱、漫画和手绘稿。缺点：不会自动产生丰富的阴阳层次。

建议管线：

```text
线稿净化 → 单像素骨架 → 感知闭合 → 区域图
        └→ 线条分级 ────────────→ 版画轮廓
区域图 ─────────────────────────→ 稀疏装饰排线
```

手绘线稿经常存在小缺口。Trapped-ball 分割会用不同尺寸的“球”逐步填充被线条包围的空间，适合从不完全闭合的线稿建立区域。关于感知闭合的研究则根据良好连续、转角和紧凑度，在交汇处寻找最合理的闭合路径。

- Trapped-ball 方法原始论文：<https://cg.cs.tsinghua.edu.cn/papers/TVCG_2009_cartoon.pdf>
- *Finding Perceptually Closed Paths in Sketches and Drawings*：<https://doi.org/10.1109/TPAMI.2003.1190573>
- 显式线稿区域分割：<https://www.sysu-imsl.com/files/PG2021/line_art_colorization_pg2021_main.pdf>

### B. 再光照版：线稿加光源生成版画

用户指定光线方向、软硬和高度。系统根据闭合区域、边界距离、形状对称性和线条提示生成一份新的调子图，再把调子翻译成排线。

```text
纯线稿 + 光源
    ↓
区域与形体假设
    ↓
合成明暗图
    ↓
嵌套排线 + 原始轮廓
```

这一模式的价值是创作：同一张线稿可生成侧光、顶光和逆光三个版画版本。风险是算法可能把平面误解成曲面。界面必须明确称为“再光照”，不能让用户误以为这是原始明暗。

第一版不需要机器学习。可以给每个区域提供平面、凸面、凹面、圆柱和自动五种形体假设，用距离场与方向场生成可预测的调子。后续可将 SHAD3S 一类模型作为可选建议器。

### C. 调子素描版：只读一张完整素描

这是最适合 Etchloom 的路线。底图看起来仍是一张素描，但在低频上保留阴阳灰调，在高频上保留轮廓和笔触：

```text
完整素描
├─ 低通分量 → 明暗区域与排线密度
├─ 中频分量 → 形体转折与材质
└─ 高频分量 → 主轮廓、细节线与细丝
```

这样最终生成阶段确实只读取素描底图，不再依赖照片。低频灰调回答“哪里应该黑”，高频线稿回答“哪里应该刻”。它与 Lu、Xu、Jia 将铅笔画拆成笔触层和调子层的思路一致。

- *Combining Sketch and Tone for Pencil Drawing Production*：<https://diglib.eg.org/items/a5ae8570-62a0-4afa-820f-194888f84c73>

## 推荐的数据设计

如果“只用素描底图”是产品层面的要求，可以保存一张可见的灰度素描，同时在方案内部保留三个可从它复算的缓存：

- `tone`: 低频调子，决定五档明暗区域。
- `stroke`: 结构笔触置信度，决定轮廓骨架。
- `ridge`: 单线细脊，保护胡须、发丝和植物茎。

这仍然只有一个创作来源，不需要保留原照片；缓存只是从素描派生的分析结果。方案文件可独立恢复和复现。

如果要求文件层面也只能有一张普通灰度图，那么必须确保素描生成阶段保留足够低频调子。当前近白的结构素描不满足这个条件。

## 与版画排线的衔接

调子素描不应该直接二值化。应先把低频明度映射为五个嵌套调子层：

1. 高光：留白。
2. 亮中调：稀疏单向排线。
3. 中调：增加同方向邻线。
4. 暗调：加入第二方向交叉排线。
5. 深暗：有限的第三方向短线和墨团，同时保留亮孔。

Tonal Art Maps 的核心经验是暗层继承亮层已有笔触，使调子随层级稳定增加，并维持跨分辨率的一致性。

- Real-Time Hatching：<https://gfx.cs.princeton.edu/proj/hatching/>

## 对 Etchloom 的推荐

建议新增“底图来源”而不是替换现有照片流程：

- **照片分析**：保留原始明暗，适合忠实转换。
- **完整素描**：最终阶段只读取调子素描，适合进一步抽象和手工修改。
- **纯线稿再光照**：由用户决定光源和区域形体，适合创造新版本。

最值得先做的是“完整素描”模式。它可以复用现有净化、骨架、细脊和排线模块，只需把结构素描升级为同时包含低频调子的生产底图，并让生成器仅从这张底图重新分离 `tone / stroke / ridge`。随后加入一个诊断开关，对比当前双输入结果与素描单输入结果。

## 验收方法

对同一张照片生成完整素描，然后删除原照片数据，仅从素描重建版画：

- 五档区域的黑度顺序必须保持。
- 主轮廓位置与双输入版本的平均偏差不超过 2 像素。
- 胡须和枝条仍保持单线、渐隐和较低权重。
- 暗部覆盖率与双输入版本差异控制在 10% 内。
- 保存后的方案不含原照片，也能离线得到逐点一致的刻线路径。

如果这些指标成立，这条路线不仅可行，还能把“素描底图”变成 Etchloom 中真正可编辑、可分享、可再制版的中间作品。
