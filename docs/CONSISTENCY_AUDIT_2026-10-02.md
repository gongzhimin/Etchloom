## 验证边界

- SVG 表示当前页面结构、布局关系与主要视觉材质，不承诺与浏览器逐像素一致。
- 自动化测试验证代码行为与入口装配；它们不等同于所有浏览器尺寸、字体及操作系统的视觉回归测试。
- 可选模型服务和平台安装包需在对应服务及构建环境中单独验证。

## 后续同步规则

调整双阶段布局时，同步检查两份 README 示意图、`docs/04_ui_design_system/` 与 `src/ui/` 文档。改动纸张、木纹、logo 等运行时资源时，同步检查 `scripts/prepare-desktop.cjs`。新增或删除测试后，按 `npm test` 输出更新测试矩阵。
