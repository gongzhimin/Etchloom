## 1. 清新浅色工坊无障碍色彩与对比度 (WCAG 2.1 AA / AAA Compliance)

Etchloom v2.0 浅色主题全面对标 **Web Content Accessibility Guidelines (WCAG 2.1)** 对比度标准，根除暗色模式下常见的暗灰低对比与视觉疲劳问题：

| 文本/前景元素 | 背景材质 | 颜色组合 | 对比度 (Contrast Ratio) | 达标等级 |
| :--- | :--- | :--- | :--- | :--- |
| 正文排印 (`--text-primary`) | 纯白卡片 (`#ffffff`) | `#1e293b` on `#ffffff` | **14.2 : 1** | **WCAG AAA** (远超 7.0:1 严苛标准) |
| 二级辅助标签 (`--text-secondary`) | 纯白卡片 (`#ffffff`) | `#475569` on `#ffffff` | **7.5 : 1** | **WCAG AAA** (超 7.0:1) |
| 弱化时间戳 (`--text-muted`) | 控件底色 (`#f1f5f9`) | `#94a3b8` on `#f1f5f9` | **3.8 : 1** | **WCAG AA** (大字号/次级元数据合规) |
| 暖铜激活按钮文案 (`#ffffff`) | 暖铜金属底色 (`#c07a38`) | `#ffffff` on `#c07a38` | **4.8 : 1** | **WCAG AA** (超 4.5:1 正文标准) |
| 典藏纸面印样 (`#0f172a`) | 象牙白画纸 (`#faf7f0`) | `#0f172a` on `#faf7f0` | **16.5 : 1** | **WCAG AAA** (极致印刷级黑白阶调) |

## 2. 现行键盘与鼠标交互表 (Active Interactions)

| 交互行为 | 触发方式 | 生效区域 | 状态反馈 |
| :--- | :--- | :--- | :--- |
| **步骤卡片特写灯箱** | 鼠标左键点击步骤视口 或 悬浮胶囊 `[⛶ 特写]` | 7 阶段步骤卡片任一画布 | 唤起 Lightbox 模态框，居中呈现高保真画作并提供平移缩放 |
| **独立图层分步导出** | 点击悬浮胶囊 `[⬇ 导出]` | 7 阶段步骤卡片任一视口 | 分步调度 Universal Exporter：0/1/2/6 输出 PNG，3/4/5 输出纯矢量 SVG |
| **悬浮微交互胶囊唤现** | 鼠标悬停至步骤卡片视口区域 | 步骤卡片视口 (`.card-viewport`) | `opacity: 1` 平滑浮现半透明微毛玻璃按键，离开时自动隐退 |
| **局部物理像素放大镜** | 按住 `Alt` 键 + 鼠标悬停 | 主铜版画布 (`#canvas`)、卡片预览画布 | 呈现 160px 圆形放大镜，以 4 倍放大率检验微米级刻痕 |
| **超高清视口缩放** | 鼠标滚轮向上/向下 | 特写模态框画布视口 (`#modalOverlay`) | 缩放比例在 100% ~ 500% 之间平滑无级过渡，工具条显示动态百分比 |
| **视口漫游平移** | 按住鼠标左键并拖拽 | 特写模态框画布视口 | 鼠标呈抓手态 (`grabbing`)，画布跟随位移实时漫游 |
| **双击重置视口** | 鼠标双击 | 特写模态框视口区域 | 恢复至 100% 原始比例并居中 |
| **关闭模态对话框** | 按下 `Esc` 键 或 点击右上角 `✕` | 特写模态框、上版向导模态框 | 模态框平滑淡出并释放视口焦点 |
| **活动日志抽屉展开/折叠** | 点击底部遥测栏 `[📋 运行日志]` 或 日志栏头部 | 底部遥测栏 / 活动日志栏 | 抽屉在 32px 折叠条与 96px 展开窗之间平滑滑出与收起 |
| **工作流模式全局切换** | 点击顶栏 Tab (`[算法母版设计]` / `[虚拟铜版工坊]`) | 页面顶栏 (`.workspace-tabs`) | 切换 `body.mode-master` 与 `body.mode-plate`，侧边栏联动过滤无关阶段 |

## 3. 规划中的辅助交互 (Planned Accessibility)

以下快捷键已纳入下一阶段工程规划，当前尚未在生产代码中全局绑定：
- `[PLANNED]` `Ctrl + Z` / `Cmd + Z`：撤销铜版上一笔刻绘动作；
- `[PLANNED]` 数字键 `1` ~ `4`：快速在刻针、干刻针、防蚀漆、刮磨器之间切换；
- `[PLANNED]` `Space + 鼠标拖拽`：主工作区全局画布平移。
