## 1. 现行键盘与鼠标交互表 (Active Interactions)

| 交互行为 | 触发方式 | 生效区域 | 状态反馈 |
| :--- | :--- | :--- | :--- |
| **局部物理像素放大镜** | 按住 `Alt` 键 + 鼠标悬停 | 主铜版画布 (`#canvas`)、卡片预览画布 | 显示 160px 圆形放大镜，放大 4 倍 |
| **关闭模态对话框** | 按下 `Esc` 键 或 点击右上角 `&times;` | 特写模态框 (`#modalOverlay`)、上版向导 | 模态框平滑淡出并释放视口焦点 |
| **超高清视口缩放** | 鼠标滚轮向上/向下 | 特写模态框画布视口 | 缩放比例在 100% ~ 500% 之间平滑过渡 |
| **视口漫游平移** | 按住鼠标左键并拖拽 | 特写模态框画布视口 | 画布跟随鼠标位移实时平移 |
| **双击重置视口** | 鼠标双击 | 特写模态框视口区域 | 恢复至 100% 原始居中比例 |

## 2. 规划中的辅助交互 (Planned Accessibility)

以下快捷键已纳入下一阶段工程规划，当前尚未在生产代码中全局绑定：
- `[PLANNED]` `Ctrl + Z` / `Cmd + Z`：撤销铜版上一笔刻绘动作；
- `[PLANNED]` 数字键 `1` ~ `4`：快速在刻针、干刻针、防蚀漆、刮磨器之间切换；
- `[PLANNED]` `Space + 鼠标拖拽`：主工作区全局画布平移。
