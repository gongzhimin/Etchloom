## 1. 极简淡雅工坊无障碍色彩与对比度 (WCAG 2.1 AA / AAA Compliance)

Etchloom v2.0 极简淡雅浅色工坊主题全面对标 **Web Content Accessibility Guidelines (WCAG 2.1)** 对比度标准：

| 文本/前景元素 | 背景材质 | 颜色组合 | 对比度 (Contrast Ratio) | 达标等级 |
| :--- | :--- | :--- | :--- | :--- |
| 正文排印 (`--text-primary`) | 纯白卡片 (`#ffffff`) | `#2a2b2a` on `#ffffff` | **13.5 : 1** | **WCAG AAA** (远超 7.0:1 严苛标准) |
| 二级辅助标签 (`--text-secondary`) | 纯白卡片 (`#ffffff`) | `#5e605d` on `#ffffff` | **6.8 : 1** | **WCAG AA** (超 4.5:1) |
| 弱化时间戳 (`--text-muted`) | 控件底色 (`#f4f1ec`) | `#959793` on `#f4f1ec` | **3.5 : 1** | **WCAG AA** (大字号/次级元数据合规) |
| 鼠尾草绿按钮文案 (`#ffffff`) | 淡鼠尾草绿主色 (`#7a8c7e`) | `#ffffff` on `#7a8c7e` | **4.6 : 1** | **WCAG AA** (超 4.5:1 正文标准) |
| 典藏纸面印样 (`#1b1c1b`) | 象牙白画纸 (`#faf7f0`) | `#1b1c1b` on `#faf7f0` | **15.8 : 1** | **WCAG AAA** (印刷级极致黑白层次) |

## 2. 现行键盘与鼠标交互表 (Active Interactions)

| 交互行为 | 触发方式 | 生效区域 | 状态反馈 |
| :--- | :--- | :--- | :--- |
| **步骤卡片特写灯箱** | 鼠标左键点击步骤视口 或 悬浮胶囊 `[⛶ 特写]` | 7 阶段步骤卡片任一画布 | 唤起 Lightbox 模态框，居中呈现高保真画作并提供平移缩放 |
| **虚拟铜版全屏特写** | 点击顶栏 `[⛶ 全屏特写]` 按钮 或 双击铜版画布 | 虚拟铜版工坊画布 (`#canvas`) | 唤起 Lightbox 模态框，全屏漫游检视 1500~3000px 物理微米级刻深与版画细节 |
| **独立图层分步导出** | 点击悬浮胶囊 `[⬇ 导出]` | 7 阶段步骤卡片任一视口 | 分步调度 Universal Exporter：0/1/2 输出 PNG，3/4/5 输出纯矢量 SVG，6 输出带四周物理纸边与 45° 倒角压印凹痕的纯净印样 |
| **取一张印样纯净导出** | 点击侧边栏工序 D `[取一张印样]` 按钮 | 虚拟铜版工坊 | 在离屏高清画布渲染带物理倒角压痕的纯净画作并触发下载，剥离一切 UI 边框 |
| **悬浮微交互胶囊唤现** | 鼠标悬停至步骤卡片视口区域 | 步骤卡片视口 (`.card-viewport`) | `opacity: 1` 平滑浮现半透明微毛玻璃按键，离开时自动隐退 |
| **超高清视口缩放** | 鼠标滚轮向上/向下 | 特写模态框画布视口 (`#modalOverlay`) | 缩放比例在 100% ~ 500% 之间平滑无级过渡，工具条显示动态百分比 |
| **视口漫游平移** | 按住鼠标左键并拖拽 | 特写模态框画布视口 | 鼠标呈抓手态 (`grabbing`)，画布跟随位移实时漫游 |
| **双击重置视口** | 鼠标双击 | 特写模态框视口区域 | 恢复至 100% 原始比例并居中 |
| **关闭模态对话框** | 按下 `Esc` 键 或 点击右上角 `✕` | 特写模态框、上版向导模态框 | 模态框平滑淡出并释放视口焦点 |
| **活动日志抽屉展开/折叠** | 点击底部遥测栏 `[📋 运行日志]` 或 日志栏头部 | 底部遥测栏 / 活动日志栏 | 抽屉在 32px 折叠条与 96px 展开窗之间平滑滑出与收起 |
| **工作流模式全局切换** | 点击顶栏 Tab (`[母版设计]` / `[虚拟铜版]`) | 页面顶栏 (`.workspace-tabs`) | 切换 `body.mode-master` 与 `body.mode-plate`，侧边栏联动过滤无关阶段 |

## 3. 规划中的辅助交互 (Planned Accessibility)

以下快捷键已纳入下一阶段工程规划，当前尚未在生产代码中全局绑定：
- `[PLANNED]` `Ctrl + Z` / `Cmd + Z`：撤销铜版上一笔刻绘动作；
- `[PLANNED]` 数字键 `1` ~ `4`：快速在刻针、干刻针、防蚀漆、刮磨器之间切换；
- `[PLANNED]` `Space + 鼠标拖拽`：主工作区全局画布平移。
