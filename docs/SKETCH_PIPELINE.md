# 从照片到结构素描，再到版画

更新：2026-09-13。

## 为什么增加中间层

直接从照片梯度生成版画，会把摄影噪声、光照和材质纹理放在同一层处理。结构素描的作用是先回答“哪些线值得画”，再由版画语法回答“这些结构应该怎样刻”。

成熟研究通常不会让素描线稿独自承担全部信息。Lu、Xu、Jia 将铅笔画拆成表达形体的笔触层和表达明暗的调子层，再组合两者；这与 Etchloom 的轮廓/细丝和排线/暗部划分高度一致。

- Lu, Xu, Jia, *Combining Sketch and Tone for Pencil Drawing Production*: <https://diglib.eg.org/items/a5ae8570-62a0-4afa-820f-194888f84c73>

XDoG 扩展高斯差分，使边缘检测可以产生更有表现力的线稿、排线和抽象效果。OpenCV 的 `pencilSketch` 也采用边缘感知风格化参数，说明“先简化区域、再强调结构”是成熟的工程路线。

- Adobe Research, *XDoG*: <https://research.adobe.com/publication/xdog-an-extended-difference-of-gaussians-compendium-including-advanced-image-stylization/>
- OpenCV 非写实渲染与 `pencilSketch`: <https://docs.opencv.org/4.x/df/dac/group__photo__render.html>

## Etchloom 初版

当前版本使用两个尺度的平滑图近似 XDoG。较宽尺度与较细尺度之差表示暗笔触置信度；软阈值避免形成生硬的二值边缘。它生成一张独立结构图：

```text
净化灰度 ─────────────────────────→ 排线密度、暗部、背景调子
    ├→ 多尺度细脊检测 ────────────→ 胡须等细丝
    └→ 多尺度差分 → 结构素描 → 单像素骨架 → 分级矢量轮廓
```

结构素描先经过 Zhang–Suen 细化，再按连通轮廓追踪为矢量路径。路径结合整条连通结构的跨度、局部对比与闭合程度，分为主轮廓、内部结构和细节三级。即使轮廓在拐角或交汇点被拆成短段，它也会继承所属大结构的等级。

这些路径绕过随机的“失落与重现”裁切，并在周围建立与等级相符的留白带，防止排线覆盖物体边界。主轮廓采用更明确的线宽；结构线较细；细节线最轻且端点渐隐。细丝仍从净化灰度的多尺度暗脊独立检测，避免把胡须变成双边粗轮廓。

因此提高“素描结构”会增加值得描绘的结构，但不会改变大面积区域的基础明度。强度为 0 时，系统回到原有的灰度梯度轮廓流程。

## 下一步

当前版本已经完成轻量的切线流积累、方向滞后连接，以及外剪影、遮挡边、明暗转折和材质提示四类轮廓语义。下一步是：

1. 让局部净化与素描强度共享区域遮罩，分别保护皮肤、毛发和背景。
2. 增加可切换的原图、净化图、结构素描、矢量骨架和最终版画诊断视图。
3. 在真实人像、动物毛发、建筑和密集植物样片上建立语义误分级记录，再校准分类阈值。

当前工作台的并排对照已经改为“结构素描 / 最终版画”，并显示净化与素描强度。它用于直接定位结构提炼和版画语法之间的差异；完整四联诊断视图仍列为下一阶段。

机器学习素描模型暂不进入默认流程。它们可以产生更强的语义概括，也可能创造照片中不存在的边缘；当前实现优先保证本地运行、可解释和固定参数复现。
