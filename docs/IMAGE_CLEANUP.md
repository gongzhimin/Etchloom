# 图像净化与细节可信度

更新：2026-09-13。

## 目标

照片噪声、JPEG 块、锐化光晕和传感器颗粒在灰度化后会变成伪边缘。Etchloom 的净化阶段要压低这些不稳定高频，同时保留轮廓、胡须、毛发和真实表面转折。

## 当前管线

```text
感知灰度 → 明暗校正 → 噪声估计 → 自适应保边扩散
        → 明暗与轮廓生成 → 跨尺度细节可信度 → 刻线语法
```

噪声估计使用局部拉普拉斯残差的中位数，强边缘只占少数像素，因此不会主导结果。“净化”参数与测得的噪声共同决定扩散次数：干净图片只接受较弱处理，颗粒明显的图片会获得更强平滑。扩散权重随相邻灰度差下降，使平坦区域的颗粒互相平均，而主体边界基本停止扩散。

微细节不再由单尺度 Sobel 直接决定。算法比较半径 1 与半径 3 的梯度强度和方向：多个尺度都存在、方向一致的结构得到高可信度；只在最细尺度出现的随机颗粒被压低。落在 8 像素周期边界且缺少大尺度支撑的响应还会被降权，用于减少常见 JPEG 栅格痕迹。

## 界面

- **保留纹理（25）**：适合清晰扫描、插画和已经降噪的图片。
- **平衡（55）**：默认设置，适合大多数手机与相机照片。
- **干净（82）**：适合高 ISO、JPEG 压缩或大面积平滑背景。
- **净化强度**：可在预设基础上连续调整；非预设数值显示为“自定义”。

界面会显示估计噪声百分比。它是算法内部的相对指标，不等同于相机信噪比。

## 下一步

1. 上传阶段同时保留色度边界，解决不同颜色但亮度接近的物体分界。
2. 将光照渐变与材质纹理分开，避免墙面阴影被当作表面刻痕。
3. 建立相机颗粒、JPEG、扫描网点和锐化光晕的固定样片。
4. 允许局部调节净化强度，使皮肤、毛发和背景采用不同门槛。
