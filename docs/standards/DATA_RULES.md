# 统一数据表达与类型度量规范

## 1. 目的与范围

本规范规定全系统几何数据、物理量、时间戳与二进制内存布局的通用度量单位与数据表达约定；各实体的具体字段结构由 `design/DATA_DICTIONARY.md` 定义。

## 2. 规则正文

### §2.1 物理量度量与单位系统
系统涉及古典版画物理仿真与现代高分辨率渲染，所有数值必须严格遵守以下物理量纲定义：

| 物理量 | 权威量纲单位 | 取值范围与精度 | 范例 |
| :--- | :--- | :--- | :--- |
| **版面坐标 $(x, y)$** | 离散像素 (`px`) | $x \in [0, W), y \in [0, H)$ | $(450, 330)$ |
| **划痕/刻槽深度** | 微米 (`μm`) / 归一化浮点 | 物理显示 $[0.0, 45.0]\,\mu\text{m}$；内部数组 $[0.0, 1.0]$ | `depth: 0.35` ($\approx 15.75\,\mu\text{m}$) |
| **腐蚀时间** | 真实秒数 (`s`) | 浮点数，显示保留 1 位小数 | `elapsed: 5.4` |
| **针尖直径** | 毫米 (`mm`) / 像素 (`px`) | 物理针尖 $[0.1, 5.0]\,\text{mm}$；画布光标 $[1, 50]\,\text{px}$ | `needleMM: 0.3` |
| **酸液浓度 / 压力** | 百分比 (`%`) / 归一化浮点 | $[0, 100]\% \leftrightarrow [0.0, 1.0]$ | `acid: 0.45` ($45\%$) |
| **纸张尺寸** | 毫米 (`mm`) | $[50, 1000]\,\text{mm}$ (默认 $254\,\text{mm}$ / 10 英寸) | `paperMM: 254` |

### §2.2 时间戳与导出命名格式
1. **导出文件时间戳规范**：
   所有下载与导出文件（SVG、PNG、JSON 备份）中的时间戳必须使用紧凑且易于文件系统排序的格式：
   ```text
   YYYYMMDD-HHmmss
   ```
   格式范例：`Etchloom-plate-20261008-223000.json`、`Etchloom-proof-20261008-223000.png`。
2. **元数据时间戳**：
   JSON 数据结构内部的创建时间统一使用标准 ISO 8601 UTC 字符串：
   ```json
   "timestamp": "2026-10-08T14:30:00.000Z"
   ```

### §2.3 内存布局与 TypedArray 原则
1. **零 GC 压力连续内存**：
   图像与版面密集计算核心（`depth`, `exposed`, `blocked`, `burr`）必须使用一维扁平 TypedArray，禁止在逐像素循环中分配动态对象。
2. **定长类型选择**：
   - 浮点连续场：`Float32Array`（4 字节对齐）
   - 布尔阻断掩码：`Uint8Array`（1 字节）
   - 颜色通道缓存：`Uint8ClampedArray`（Canvas ImageData 兼容）

## 3. 与其他规范的关系

- 具体数据实体与 Schema 由 `docs/design/DATA_DICTIONARY.md` 权威定义；
- 数据编码与网络序列化规则以 `standards/API_RULES.md` 为准；
- 冲突时以 `standards/DOCUMENT_RULES.md` 为准。
