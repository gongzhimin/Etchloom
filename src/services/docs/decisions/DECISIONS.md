## 2. 决策记录

### DEC-SERV-001: 采用三态智能探活代理体系

- **日期**：2026-10-08
- **状态**：Accepted
- **上下文**：不同用户的计算硬件差异极大，部分用户有 NVIDIA 显卡并启动了 Python 服务，部分用户在纯浏览器中运行，部分用户完全离线。
- **决策**：设计 `remote-python`、`browser-webai` 和 `offline-analytical` 三态自适应模式，由网关统一探测与分发。
- **后果**：兼顾极致画质（PyTorch GAN）与极致便携（纯 JS 零安装）；网关逻辑需要维护多种后端的兼容性。
- **替代方案**：强制要求用户安装 Python 环境（门槛过高，严重阻碍开箱即用，被否决）。

### DEC-SERV-002: Fail-Safe 零阻断平滑降级策略

- **日期**：2026-10-09
- **状态**：Accepted
- **上下文**：本地微服务可能因为显存不足（OOM）或进程意外关闭而中断，前端若抛出未捕获网络异常会导致创作流程中断。
- **决策**：网关层严格拦截所有网络级和协议级异常，超时或失败时静默返回 `null`，驱动核心管线自动启用自适应 DoG 与经验几何回退。
- **后果**：用户创作流程永不崩溃，体验连续；开发时需通过日志监控排查服务异常。
- **替代方案**：向用户弹出错误对话框并终止生成（严重破坏交互连续性，被否决）。

### DEC-SERV-003: 跨进程微服务仅绑定本地回环端口

- **日期**：2026-10-10
- **状态**：Accepted
- **上下文**：若 Python 推理服务绑定到 `0.0.0.0`，可能暴露本地神经网络推理接口至局域网，存在潜在安全隐患。
- **决策**：服务端严格绑定 `127.0.0.1:7861` 本地回环地址，并校验请求 Origin，禁止外部跨域请求。
- **后果**：保证了用户本地计算环境的安全隔离。
- **替代方案**：无校验全网监听（存在内网安全风险，被否决）。
