# UI 页面布局与交互设计方案 (UI-DESIGN-UI)

## 1. 页面/视图结构与路由

界面基于单一 SPA 页面架构，通过顶栏工作流导航在两套沉浸式工坊模式之间无刷新流转：

```text
+--------------------------------------------------------------------------+
| 顶栏: [Etchloom Logo] | [模式1: 制作母版] [模式2: 虚拟铜版] | [关于] [语言切换] |
+--------------------------------------------------------------------------+
|                                                                          |
|  [模式 1: 制作母版 工作区]                                               |
|  +-----------------------------+  +-----------------------------------+  |
|  | 左侧控制面板                |  | 中央高精预览视口                  |  |
|  | - 选图与预设                |  | - 亚麻纸纹背景画布                |  |
|  | - 曝光/色调/灵敏度滑块      |  | - 状态覆盖层 (初始/计算中/就绪)   |  |
|  | - [制作铜版 ->] 主动作 CTA  |  | - 灯箱放大镜 (Loupe) 1:1 特写     |  |
|  +-----------------------------+  +-----------------------------------+  |
|  | 底部: 七阶段折叠式横向胶片卡片栏 (StepFlowGrid)                     |  |
|  +--------------------------------------------------------------------+  |
|                                                                          |
|  [模式 2: 虚拟铜版工坊 工作区]                                           |

|  +-----------------------------+  +-----------------------------------+  |
|  | 专属工序控制抽屉            |  | 铜版工作台视口                    |  |

|  | - 试印纸张与油墨预设        |  | - [全屏特写] 沉浸式灯箱           |  |
```

## 2. 核心交互流程与状态反馈

1. **制作母版流程**：用户选择照片 -> 状态机进入 `COMPUTING`，画布立即清空杜绝残影 -> 进度条随阶段事件推进 -> 完成后激活【制作铜版 ->】引导；
2. **铜版工坊四步工序流转**：
   - **工序 1 · 上版 (Transfer)**：显示母版提取线条数，选择蚀刻/干刻与目标精度 -> 点击上版 -> 触发安全覆写拦截防护；
   - **工序 2 · 亲手刻绘 (Inscribe)**：选择物理工具（刻针、刮磨器、干刻针、防蚀漆），支持撤销与半径调节；
   - **工序 3 · 控制腐蚀 (Etch)**：实时展示腐蚀秒数、平均深度微米值与分档（轻蚀/标准/深蚀/防过蚀），支持开始/暂停与一键重置；
   - **工序 4 · 试印与导出 (Print & Export)**：选择 4 种纸面预设（rough、smooth、linen、rosaspina），渲染纯净压印画作并导出。

## 3. 组件清单与属性规范

| 组件名称 | 对应源文件 | 核心职责与属性规范 |
| :--- | :--- | :--- |
| **`StepFlowGrid`** | `src/ui/components/step-flow-grid.js` | 七阶段横向胶片卡片栏；支持宽高比自适应 (`setAspectRatio`)、三语实时切换 (`updateLocale`) 与展开/折叠切换。 |

## 4. 响应式布局与无障碍 (A11y)

1. **极淡清新配色**：
   - 亚麻纸白底色：`#faf8f5`；
   - 鼠尾草绿主色：`#536957`；
   - 分割线：`#eae5dc`；
   - 暖炭灰正文：`#2a2b2a`；
   - 保证文本对比度符合 WCAG AA 级标准 ($\ge 4.5:1$)。
2. **语义化 DOM 与 ARIA 属性**：
   - 导航使用 `<nav>`，主按钮具有明确的 `aria-label` 与 `aria-selected`；
   - 对话框使用 `role="dialog"` 与 `aria-modal="true"`；
   - 外部链接强制配置 `rel="noopener noreferrer"` 与 `target="_blank"`。
3. **响应式断点**：针对移动与窄屏断点自适应单列排列，抽屉平滑浮动收起。

## 5. 异常与边界展示方案

- **超大图像警告与缩放**：超过 1200 万像素时在提示条显式标注并自动等比缩小，防止显存崩溃；
- **空输入阻断**：未选择照片时禁用生成与调参控件；
- **酸蚀过蚀警报**：腐蚀时间超过 14.0s 时，进度条切换为陶土色高亮警示；
- **覆写弹窗确认**：当铜版已有刻画深度时，重新上版必须弹窗经用户二次确认后方可覆写。
