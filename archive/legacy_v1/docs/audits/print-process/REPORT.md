# 制版与压印代码审计

检查对象：当前工作区代码。仅新增审计脚本及结果，不修改生产算法。

## 方法

- `npm test`：73 项通过。
- `node scripts/audit-print-process.cjs`：提取 index.html 的实际内联脚本，在 Node VM 中执行原始 render()、etch()。DOM 使用最小替身，Canvas 使用 ImageData 接收器，输出真实 RGBA 为 PNG。
- 固定测试版包含细平行线、交叉线、连续刻深阶调；逐一改变印刷参数。查看 comparison.png 验证可见结果。
- 本次是引擎级数值与图像测试，没有测试浏览器按钮交互，也没有使用实体铜版印样校准。

## 发现

1. index.html:49 的压印核心为 `(1-exp(-depth*5))*ink*(0.25+pressure*0.95)*variation + tone*ink`，随后乘纸色。Alpha 恒为 255；严格说是 RGB 黑度控制，而非 alpha 透明度，但视觉效果符合用户所说的深浅变化。
2. 细纹纸、tone=0：压力 0/墨量144 与压力100/墨量30 输出的 76800 个像素完全相同。压力无独立接触模型；压力为0仍保留0.25的系数。
3. 擦版留墨只是全局 tone*ink。空白区也变暗，没有擦拭方向、槽口墨或独立表面残墨状态。
4. 纸张仅改变像素级噪声及局部黑度乘数。细纹纸连续两次印样完全相同；粗纹纸改变22257个像素，但机制是seed偏移后的噪声，没有纤维/接触/吸墨扩散模型。
5. 状态只有depth/exposed/blocked等，没有槽内墨、表面墨、纸面接收墨。印刷不修改版面状态本身并非错误，但这里也没有另行维护墨量转移或补墨状态。
6. 腐蚀确实加深并向四邻域扩散，且尊重blocked；不是纯显示特效。但固定四邻域、固定像素尺度没有按纸幅分辨率校准。100与400像素测试版中心脉冲经10秒腐蚀后，截面RMS扩散均为0.74715像素；假定同为254mm纸幅，分别为1.89775与0.47444mm。此为尺度探针，不是实体腐蚀预测。
7. index.html:49 压印强制清空约13/900版宽的边带，是平面留白，非纸面压痕，且可能清除接近版边的内容。
8. src/ui/output-ui.js 的导出设计PNG走直接图案绘制，不经过render()压印；index.html的“取一张印样”才走压印引擎。两种PNG需区分。
9. src/ui/output-ui.js 中图案先绘到900×660缓冲，再放大到输出尺寸；高分辨率版面并不代表主体刻痕以目标分辨率重绘。外框则在目标尺寸绘制。

## 建议

优先独立维护槽内墨、表面残墨和纸面接收墨，令擦版与压力有不同作用；再引入带空间尺度的纸面起伏及墨边扩散。同步统一腐蚀/纸纹的物理尺度，消除900×660中间栅格的放大瓶颈。保留本试版作为前后对照；通过现有功能测试并不能证明材料表现成立。

结果见 results.json；带标签图集见 index.html。
