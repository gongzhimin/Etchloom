# Etchloom 痕迹系统 V2

新版生成器把照片解析为形体明暗、五档调子和连续方向场，再把这些信息翻译成有限的可印痕迹。素描只参与分析，不作为必须描满的最终骨架。

| 调子 | 输出痕迹 |
| --- | --- |
| 高光 | 留白 |
| 亮部 | 稀疏顺形线 |
| 中调 | 稳定单向排线 |
| 暗部 | 继承排线并加入交叉线 |
| 深暗 | 密集交叉线和短促黑色刻痕 |

第一版已经实现五档分区、平滑双角方向场、嵌套线层、深暗黑块和确定性随机扰动。轮廓不再默认描满，而由排线的开始、停止和负形边界首先建立。

后续按以下顺序推进：区域邻接关系与主形分离；只在负形不足时补稳定主边界；独立飞尘颗粒场；线刻、飞尘腐蚀和黑白木刻三种痕迹语法；最后接入材料、腐蚀和压印参数。
