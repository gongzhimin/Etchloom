# 版画线条纹理精进计划

更新：2026-09-13。参考样图为用户提供的两张装裱作品照片。照片中的玻璃反光、透视、纸张偏色与照明渐变不作为刻线特征学习。

## 目标

将图片从“沿像素梯度生成许多曲线”提升为“用有层级的刻线组织画面”。核心判断标准是：缩小后有清楚的大明暗，放大后能看见成束的针痕、断续轮廓和区域方向，而不是均匀的数字网纹。

## V0.1 区域线场初版 — 已完成

- 将长曲线拆为短线束，同一区域共享稳定的主方向；保留轻微的间距、端点与法向漂移。
- 交叉排线只进入中深调；极暗区以较低概率出现第三方向，避免亮部形成无意义网格。
- 弱边缘按连续区段省略，形成失落与重现的轮廓；强明暗边界保持连续。
- 五个主参数与方案格式不变；保存的旧图片方案会自动使用新线场生成。

验收：线束长度有上限；亮区不出现交叉层；弱轮廓产生间断而强轮廓连续；固定种子完全复现。以上均已有自动测试。

## V0.2 背景与主体分离 — 软件功能完成

- 建立低频前景/背景置信图，使背景也能获得稀疏、方向统一的排线。
- 在高价值主体边缘生成可控的窄亮缝，背景线束在缝外停止。
- 背景方向优先服从全局构图，主体方向优先服从形体边缘；避免两者粘成同一片纹理。
- “轮廓”参数同时控制实线轮廓与亮缝比例，不增加新的主界面参数。

实现结果：从画面边缘估计背景基调，在非纯白背景生成低频平行线场；线条遇到强局部边缘会被截断，形成主体旁的窄亮缝。纯白背景自动跳过背景层。

验收：白底产品图仍保持干净；有环境的静物与建筑图不再只剩孤立主体；主体轮廓两侧的线不会频繁穿越；缩略图辨识度不低于当前版本。

## V0.3 暗部墨团与刻痕词汇 — 软件功能完成

- 将最暗区域分为密排线、融合墨团和残留亮孔三部分，墨团边界保留可读针痕。
- 增加有限的刻痕词汇：长平行线、短交叉线、碎叶状线、点刻、局部擦痕。按区域结构选用，避免全画面随机混合。
- 线宽保持窄范围，主要用间距、层数和缺线率塑造明暗；腐蚀阶段再负责线槽扩张。
- 防止大片暗区因多层叠加统一饱和。

实现结果：最深灰阶加入受密度限制的短粗刻痕；微细节层从 Sobel 边缘和高频残差中挑选有限数量的短针痕；平面、曲面和碎片分别使用不同长度与方向稳定度。纯中间调不会生成墨团。

验收：五档灰阶仍保持黑度顺序；最暗档同时包含黑块与可见线条；中间调不会因墨团提前变黑；放大图中各刻痕类型可辨。

## V0.4 平面、曲面与植物结构 — 初版软件功能完成

- 用多尺度结构张量和边缘闭合度区分大平面、缓慢曲面与碎片区域，不依赖物体类别识别。
- 平面使用长而稳定的线束；曲面允许方向缓慢转动；植物和毛发使用短线簇及少量方向跳变。
- 加入透视一致性约束，让建筑墙面与地面的线束分别收敛，而非逐像素摆动。
- 局部“引导”工具直接编辑区域方向节点，并显示影响范围预览。

实现结果：局部对比将区域分为平面、缓转和碎片三类。平面线束更长且更稳定，缓转区域保留部分局部切向，碎片区域使用短线簇；全局方向与局部结构混合，建筑类大平面不会逐像素摆动。引导工具直接改变选区内方向，画布叠层会显示作用半径和拖动方向。

验收：建筑墙面内部方向方差低；圆柱器皿排线能表达转折；叶簇不会退化为连续毛线；局部编辑之外的路径逐点不变。

## V0.5 版面节奏与印刷校准 — 软件功能完成，实物标定待打印

- 建立大、中、小三级节奏：大明暗块、中尺度线束、小尺度断线与颗粒。
- 让线条生成考虑最终铜版尺寸、针宽、腐蚀扩张和纸张吸墨，避免 900 px 好看但 3000 px 输出过细。
- 增加屏幕黑度预估与实际印样校准表；参数文件记录纸张、墨量、压力和输出尺寸。
- 评估后台分块生成与高分辨率线场缓存，保证复杂真实照片仍能取消和恢复。

实现结果：区域线束、微细节与暗部墨团形成中、小尺度，原有明暗分区承担大尺度；尺寸面板新增目标针宽与 70–150% 增墨补偿，并实际作用于铜版转入、PNG 和 SVG 线宽。纸张毫米宽度继续决定 DPI，参数随虚拟版保存。900 / 1500 / 3000 使用同一基准路径和毫米线宽换算；生成仍在可取消 Worker 中运行。

验收：900 / 1500 / 3000 px 的结构位置一致；按相同毫米针宽输出时视觉密度接近；建立至少两种纸张、三档压力的实物对照；记录浏览器耗时与峰值内存。

性能记录：900 × 660 浏览器样片生成 2371 条路径（825 组线束、1486 处微细节），约 0.30 秒，界面工作集估算 24.5 MB。Node 合成基准生成 7187 条路径，约 0.34 秒，进程峰值 RSS 193 MB；具体机器结果保存在 `BENCHMARK.json`。

## 固定评估样片

每一阶段使用相同图片、裁切、参数和种子生成前后对照：器皿静物、花束、建筑与天空、密集植物、人像、低对比照片、透明背景对象。当前自动测试使用程序化替代图；视觉验收需补充获得授权的真实照片。用户提供的两张大师作品只作为线条组织参考，不直接训练、复制或作为待转换输入。

每张样片同时检查三个尺度：整幅缩略图判断大明暗，100% 视图判断线束和边界，印样尺寸判断纸面黑度。每次只改变一个算法层，保留旧结果和方案文件，避免用增加线条数量掩盖结构退步。

## 后续实物与审美验收

软件侧计划已经完整接入。剩余工作需要实际打印条件：用同一铜版分别测试至少两种纸、三档压力和三档补偿，测量线宽扩张与暗部堵塞，再把结果写成纸张预设。没有实物样张前，界面的针宽与补偿是明确的几何换算，不冒充材料标定结果。
