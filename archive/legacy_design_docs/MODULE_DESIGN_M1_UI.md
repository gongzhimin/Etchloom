## 1. 行业 UI 设计规范与人机工效准则调研 (UI Ergonomic Standards)

为彻底扭转传统工具类软件“布局僵硬、状态不透明、大图卡顿、视口塌陷”等缺陷，Etchloom v2.0 全面引入国际人机工效与顶级创意工作台（如 Adobe Photoshop, Figma, Blender, DaVinci Resolve）的设计准则：

### 1.1 国际人机交互工程规范 (ISO 9241-110 / ISO 9241-210)
1. **任务适宜性 (Suitability for the Task)**：
   - 界面严格遵循“当前只呈现当前任务所需控件”。系统具备两大互斥模式：**算法母版设计模式 (Algorithm Master)** 与 **虚拟铜版工坊模式 (Virtual Plate Studio)**。
   - 在算法母版模式下，侧栏严格只展示 Drawer 00（图像感知）、Drawer 01（轮廓透视）、Drawer 02（曲面排线），隐藏一切铜版物理工具；
   - 在虚拟铜版模式下，侧栏动态切换为 Drawer 03（针尖、防蚀漆、酸液、棉纸、压印），隐藏算法生成滑块，彻底消除跨阶段误触困扰。
2. **自我描述性与确定性反馈 (Self-Descriptiveness & Nielsen Heuristic #1)**：
   - **0.1 秒原则 (Immediate Response)**：按钮点击、滑块微调必须在 100ms 内给予视觉反馈（按压光效、数值联动）；
   - **1 秒原则 (Progressive Execution)**：5 阶段管线单阶段计算控制在 1 秒以内，每完成一步立即在对应卡片 Canvas 上刷出真实图像，并附带耗时徽章（如 `[✓ 24.5ms]`）；
   - **超时熔断与自愈 (Silent Healing)**：网络推理设置 4000ms 超时熔断，超时或离线立即无感退避至本地 9ms 几何边缘算法，保证系统永不卡死。
3. **错误容限与恢复 (Nielsen Heuristics #9: Error Recovery)**：
   - 文件损坏、非法图片、离线端口均由系统内部捕获，以友好的 Toast 提示和控制台诊断信息指导用户，主界面安全复位至就绪态。

### 1.2 现代暗色主题视效与对比度规范 (WCAG 2.2 AA Standard)
1. **对比度基准**：
   - 正文与背景对比度 >= 4.5:1（主体暖米白 `#ded9cc` 在极暗墨绿底色 `#191d1a` 上对比度达 12.8:1）；
   - 关键控件与高亮边框对比度 >= 3:1（老金高亮 `#c8b67e` 对比度为 7.2:1）；
   - 杜绝纯黑（#000000）与纯白（#ffffff）刺眼冲击，采用莫兰迪微浊暗灰底基（`#191d1a`、`#202421`、`#242923`），营造典雅深邃的工坊沉浸感。
2. **状态多重编码规范 (Not Color-Alone)**：
   - 状态徽章绝不依赖单一红绿色相，必须结合图标与中英双语文字：
     - `✓ 完成 (Done)`：绿色底框 + 勾选图标；
     - `● 缓存 (Cached)`：暗绿底框 + 圆点图标；
     - `⏳ 计算中 (Computing)`：琥珀金色呼吸脉冲 + 沙漏图标；
     - `⚠ 异常退避 (Fallback)`：赭石橙色 + 警告图标。

### 1.3 创意工作台视口骨架规范 (Studio Viewport Ergonomics)
1. **非塌陷视口契约 (Non-Collapsing Viewport Contract)**：
   - 步骤流容器 `#stepFlowGridContainer` 设置 `min-height: 520px`，进入页面时立即挂载 7 组标准卡片（含骨架屏与默认示范母版），任何时刻**卡片容器高度绝不塌陷为 0**；
2. **底部下沉控制台 (Docking Console Pattern)**：
   - 运行日志控制台（Activity Log）作为主工作区最底部的下沉式抽屉（高度固定 110px，支持点击标头一键折叠），绝不横亘在视口中央抢占卡片视觉焦点。

### 3.1 响应式弹性折行规范 (Responsive Rules)
- **超宽屏幕 (>= 1600px)**：`grid-template-columns: repeat(4, 1fr)`；
- **标准桌面 (1200px ~ 1599px)**：`grid-template-columns: repeat(3, 1fr)`；
- **紧凑桌面 (760px ~ 1199px)**：`grid-template-columns: repeat(2, 1fr)`；
- **窄屏移动 (< 760px)**：`grid-template-columns: 1fr`（单列全宽堆叠）。

## 4. 步骤流卡片解剖与微观交互 (Step Card Anatomy)

每个卡片均是高度自闭环的独立交互单元：

```
+-------------------------------------------------------------+
| [03] 骨干透视轮廓                 [28.6ms] [● 缓存命中] [x] |  <-- 标头: 编号 + 标题 + 耗时 + 状态
+-------------------------------------------------------------+
|                                                             |
|                       [ Canvas 绘图视口 ]                   |  <-- 360x250 视口 (强制实时重绘)
|                                                             |
+-------------------------------------------------------------+
| 380 条空间轮廓                                              |  <-- 元数据说明
| [🔍 放大镜]        [⛶ 全屏特写]        [⬇ 独立导出图层]     |  <-- 3 大微交互按钮
+-------------------------------------------------------------+
```

1. **实时重绘保证 (Immediate Paint)**：
   - 阶段 0：绘制 900x660 原图；
   - 阶段 1：绘制高精度白底黑墨线描；
   - 阶段 2：绘制 3D 灰调等高流场及金色罗盘切线流动针；
   - 阶段 3：绘制空间近粗远细透视骨干轮廓；
   - 阶段 4：绘制曲面空间几何排线；
   - 阶段 5：绘制母版矢量合成全图；
   - 阶段 6：绘制纯棉纸凹印样成品。
2. **🔍 局部像素放大镜**：
   - 鼠标悬停按住 `Alt` 或点击按钮，弹出直径 160px 的古典悬浮放大镜（4倍物理像素插值）；
3. **⛶ 全屏特写弹窗**：
   - 点击展开 780px 宽度暗调弹窗，最大化观察笔触微观细节与元数据；
4. **⬇ 独立图层导出**：
   - 单步无损导出 PNG 位图或分层 SVG 矢量。
