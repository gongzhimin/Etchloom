# 图片引导制版：精进计划与交付记录

更新：2026-09-13。四阶段的功能已接入工作台；真实创作照片的审美验收单独保留，未用合成测试冒充已完成。

线条纹理的新一轮初版已经加入区域线束、分层交叉排线和失落轮廓。后续从背景分离、暗部墨团到实物印刷校准的完整路线见 [LINE_TEXTURE_PLAN.md](LINE_TEXTURE_PLAN.md)。

## 产品收束：单一图片工作流 — 已完成

- 新建入口只保留图片刻线；风迹、回旋、群岛、独立流体和独立迷宫不再出现在界面中，底层实现暂留用于旧虚拟版兼容。
- 日常参数收束为细节、明暗、轮廓、排线、几何纹理五项；精确曝光、黑白点、阴影、交叉排线和种子折叠到高级设置。
- 单张主预览取代四张并列候选。“生成新变奏”保留最近四次历史；新上传图片重新开始历史。
- 局部工具收束为引导、留白和保护；方案操作收束为保存、打开；转入制版固定替换当前版面。

## 第一阶段：辨识度与明暗 — 功能完成

- 225 / 450 / 900 分析，多尺度独立轮廓，明暗排线和轮廓分层。
- 曝光、黑白点、阴影压缩、百分位自动展开明暗；细节优先预设。
- 固定六类程序化基准：人像结构、静物、植物、建筑、低对比、透明图白底等效数据。真实透明 PNG 导入沿用 Canvas 白底合成。
- 已测灰度校正单调性、五档灰阶刻线面积顺序、细轮廓保留、白底留白。刻线面积是覆盖代理量，非最终重叠压印的光学密度。

## 第二阶段：排线与局部控制 — 功能完成

- 保留局部梯度导向、边缘约束、间距与线宽变化；细节预设强化连续细线。
- 方向梳理、局部留白、冻结保护、局部交叉排线和局部撤销。
- 原图与刻线并排、同位置 2 倍放大；原图会话内裁切缩放和平移。
- 已测远离编辑区域的路径不变、局部方向变化和冻结路径恢复。边界裁线以约 1.5 基准像素采样，边界附近有采样误差。

## 第三阶段：图片迷宫与混合 — 功能完成

- 明暗和局部对比决定细分尺度；墙宽、额外回路跟随明暗；强灰度跳变限制开墙。
- 轮廓 / 流线 / 迷宫权重与独立种子，流线和迷宫共享宽度预算。
- 已测可重复性、种子隔离及开墙边界约束。它是局部迷宫群，不是贯穿全图的单一可解迷宫。

## 第四阶段：后台与大幅面 — 功能完成

- Worker 后台生成、进度、取消、过期结果丢弃；原图与分析缓存分开，缓存上限 3 份。
- 实际 3000 × 2200 铜版，等比刻针、腐蚀、压印；尺寸切换可撤销。大版无损保存与恢复兼容旧版。
- 3000 px 刻线 PNG、实际尺寸印样 PNG、毫米尺寸 SVG；PNG 写入 DPI 元数据。
- 已测大版完整保存恢复、撤销尺寸、编码拒绝坏值、PNG 物理分辨率。浏览器操作已验证混合图、3000 px 制版及腐蚀，印样触发了下载；浏览器工具未返回可检查的下载文件，因此未把磁盘落盘验收记为通过。
- 性能：测试静物四张 900 px 方案约 0.97 s，混合单张约 0.28 s。固定 Node 基准 5190 路径约 305 ms、进程峰值 RSS 192.7 MiB，见 BENCHMARK.json。浏览器只提供工作集估算；高分辨率腐蚀和保存仍可能短暂占用主线程。

## 验收边界

自动测试覆盖数值、拓扑、重现性和保存恢复。真实眼睛、发丝、叶脉及复杂背景的清晰程度仍需实际图片逐张比较；暗部光学密度与纸张打印结果也未做实物校准。下一轮若继续提升视觉质量，应使用固定真实样片和相同种子对比，而非仅增加噪声与线条数量。
